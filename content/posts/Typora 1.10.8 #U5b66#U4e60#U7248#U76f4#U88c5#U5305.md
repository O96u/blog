**Typora** 是一款轻量级、所见即所得（WYSIWYG）的 **Markdown 编辑器**。与传统 Markdown 编辑器不同，Typora 实时渲染 Markdown 语法，无需左右分屏，编辑与预览完全合一，极大提升了写作专注度与效率。

官网地址：[https://typora.io](https://typora.io)

## 🌟 核心特性

### ✅ 所见即所得

-   不再需要左右两栏的“编辑+预览”界面
-   所见即所得，边写边看效果

### ✅ 完整支持 Markdown 语法

-   标题、段落、加粗、斜体
-   有序/无序列表、任务列表
-   图片、链接、引用块
-   代码块（支持语法高亮）
-   表格、脚注、数学公式（LaTeX）

### ✅ 强大的导出能力

-   支持导出为：`PDF`、`HTML`、`Word (.docx)`、`OpenOffice (.odt)`、`EPUB` 等
-   支持自定义样式（CSS），自由控制排版美感

### ✅ 插件与扩展性

-   集成图床上传（如：PicGo）
-   自动保存与恢复
-   目录大纲导航
-   支持 Vim 模式

### ✅ 多平台支持

-   macOS / Windows / Linux 均有原生客户端
-   可跨平台同步使用（搭配 Git、云盘等）

## 🧩 WordPress + Typora 写作流程

1.  在 Typora 中撰写完整 Markdown 文档
2.  使用图片链接或上传至图床（Typora 支持自定义图床）
3.  导出为 HTML 或直接复制 Markdown
4.  在 WordPress 中粘贴（建议配合插件如 “Markdown Block”）
5.  调整排版样式并发布

👉 推荐使用插件：

-   **WP Githuber MD**：支持 Markdown 直接在 WordPress 编辑器中渲染
-   **Markdown Block**：支持区块编辑器中的 Markdown 格式粘贴

* * *

## 💡 高级技巧推荐

-   使用 `侧边栏大纲` 快速跳转标题结构
-   自定义主题 CSS（Typora → 偏好设置 → 外观 → 打开主题文件夹）
-   启用 `自动保存`，防止数据丢失
-   与 Git 配合进行版本控制与协作写作
-   搭配语雀、Obsidian、Notion 做笔记整合
